# failure-taxonomy

## Summary
This dimension is the failure taxonomy mined from /home/kkourtza/.claude/projects/-home-kkourtza-Projects-SoEEDF/memory/ (~95 files, ~535 KB; I read every non-session-state memory). Eleven failure CLASSES recur three or more times each and together account for essentially every expensive debugging session recorded between 2026-08-13 and 2026-09-11: (1) declared-but-unreachable / inert knob, (2) baseline contamination and the uncontrolled second variable, (3) silent write-through to a shared or regenerated artefact, (4) stale or partial build, (5) collective behind a local guard / parallel-only wrongness, (6) a diagnostic that cannot fail or names the wrong cause, (7) stale solution state under a discard or replaced solve path, (8) a fix applied to one of N sibling models, (9) a silently wrong scalar factor (units, table axis, background reservoir), (10) a guard or floor that is itself a source or a singularity, and (11) watcher/process-management self-matching. Almost every one presented as a PHYSICS anomaly, which is what made them expensive — the diagnosis went to the model instead of the plumbing, and the user paid for the runs. The single most important meta-finding is recorded verbatim in comparison-contract-on-disk.md: "Reminders do not fire; artifacts do" — five of these classes recurred AFTER the memory warning against them was written, so mechanical detectors (a grep, a counter, a tool that refuses) are the only thing that has ever worked. Every class below has a cheap detector that would have caught it in seconds.

Measured 2026-09-09 on grubert2009_pseudo: `rho [contraction]` climbs SMOOTHLY and MONOTONICALLY from 0.757 to 0.993 over ~10 consecutive steps then crosses 1.0 (jumping to 14.46), and it does so EXACTLY as I_cond peaks and reverses direction — the textbook signature of a negative-differential-resistance branch. Aitken's omega sat at ~0.8 through the whole climb and only collapsed to its 0.05 floor ONE STEP AFTER rho had already exceeded 1, far too late. Every dt from 1e-10 to 1e-8 hit the identical failure at progressively later simulated times (5.3e-7, 9.9e-7, 1.052e-6 s): smaller dt resolves the approach more accurately but does NOT avoid it. A fixed-point (Picard) outer coupling cannot converge there regardless of relaxation schedule — and note the 'pseudo-steady is stable' belief rested on 9472 consecutive converged steps that only reached t = 9.47 ns. (b) THE AVALANCHE OUTRUNS THE ION TRANSIT. n_e e-folds in 149 ns (shortening to 33 ns) while ions need 4-7 us to cross the gap — 30-45x slower — so a cathode fall, which IS a space-charge structure, CANNOT form on that separation. This is why NO cathode fall has appeared in ANY run to date, and it makes 'what is Te doing inside the negative glow' untestable regardless of which energy closure is used. Related structural gap: SoEEDF HAS electron-electron collisions (src/CoulombTerms.C, isotropic Rockwood plus the anisotropic term of Hagelaar 2016, validated) but SoPLASMA's table pipeline NEVER invokes the `coulomb` option and never passes local n_e/N — an INTEGRATION gap, tractable engineering — yet even wired up it fixes only bulk EEDF shape at a point, NOT the spatially non-local trapping the negative glow needs. Eliseev's Coulomb-heating term was implemented and unit-validated against the authors' own numbers and is STRUCTURALLY unable to help: their S_fast is a genuinely separate non-local source that stays large where the field has collapsed, while LMEA's single-group S_iz is computed from the SAME local meanE that Joule heating sets, so it goes to ~0 in exactly the regime the term exists to correct (measured ~7-8 orders below Psrc at every step checked).
**Evidence:** outer-coupling-diverges-at-negative-differential-resistance.md; avalanche-outruns-ion-transit.md; no-electron-electron-collisions-in-soplasma.md; coulomb-heating-term-structurally-mismatched-to-lmea.md; nonlocal-kinetics-assessment.md (five papers read in full); jcpic-boeuf-standing-reference.md

**Rule:** When a run fails identically across dt, scheme and circuit topology, STOP treating it as a numerical defect: plot rho and the circuit current together and check whether contraction is lost at an I-V turning point. When a time-marched run 'fails to reach steady state', check the PHYSICAL timescale first — negative-glow convergence is a MILLISECOND-scale ambipolar process, and Boeuf's own validated PIC-MCC did not converge at 150 us on the Carlsson benchmark ('at least ten times too short'). Calibrate expectations of precision against what the kinetic literature itself achieves.

**Cost:** Days spent tuning dt, schemes and circuits against a failure none of them can fix; a correctly implemented, correctly validated physics term that can never move the needle.


## Traps
- A knob you changed produces BIT-IDENTICAL output. DETECTOR: this is CONCLUSIVE that the knob is not wired — do not re-run, grep for the READER (getOrDefault|lookup|args.found), not the declaration.
- A config $var you edited is referenced by nothing, so the run proceeds at the ORIGINAL value and exits 0. DETECTOR: grep -rqF '$'"$k" system/ constant/ etc/ — and never grep -rq "\$$k" inside double quotes, which expands $$ to the shell PID.
- A diagnostic prints nothing and you read that as health. DETECTOR: set its threshold to a value that CANNOT pass (a margin of 1e12 was used) and confirm it fires; or grep the SOURCE for the literal message text to prove the pattern can ever match.
- An edit to system/fvSolution or system/fvSchemes is silently discarded — the file is rewritten BEFORE the solve so the edit is still there when you look. DETECTOR: grep -n "cp .*system/" Allrun*, then verify in the LOG (grep -m1 "Solving for n_O2p") not the dictionary.
- A write into a cp -al tree modifies every sibling AND the source case, and rm -rf does not undo it. DETECTOR: stat -c %h must be 1 before any write. SYMPTOM TO RECOGNISE: sweep arms reporting identical dt and identical limiter tallies — check the LOGS' link count before doubting the configs.
- Two fresh cases launched at the same moment race on hardlinked constant/plasmaTables, which the solver REWRITES at start-up; the loser dies with 'Mechanism hash mismatch'. DETECTOR: give every sweep case a private copy and confirm `stat -c '%h %n' constant/plasmaTables/DLN_vs_meanE` prints 1.
- Allwmake exits 0 without rebuilding a directory whose source is newer than its .o. DETECTOR: compare each touched library's .so mtime under $FOAM_USER_LIBBIN against its source .C mtime; ls -la the .so, do not trust BUILD-COMPLETE.
- build-all.sh prints BUILD-COMPLETE while components FAILED, or refuses silently (exit 0, no marker) because a solver is still running. DETECTOR: grep -c FAIL = 0 AND grep -c BUILD-COMPLETE = 1 AND the .so exists newly-stamped.
- A new member function's definition failed to insert but the shared library still links. DETECTOR: nm -DC $FOAM_USER_LIBBIN/lib<x>.so | grep <symbol> — a .so tolerates undefined symbols until load.
- A collective behind a local patch.size() guard: DEADLOCK under `simple`, MPI_ERR_TRUNCATE under `scotch`, and one variant returns garbage that LOOKS LIKE A PHYSICS FAILURE (-1e+300). DETECTOR: per-rank Pout probes bracketing each construction, and run the same case under BOTH decompositions.
- fvMatrix::residual() on a decomposed field reports ~1e-12 while the true residual is ~6.5e9. DETECTOR: cross-check against a plain Python finite difference on the raw processor*/<t>/ values; use explicit fvc:: arithmetic for any outer residual.
- A raw `break` out of `while (pimple.loop())` kills every `if (pimple.finalIter())` call. DETECTOR: grep the loop body for finalIter() before adding any early exit, then verify with a COUNT in the log (updates vs timesteps) — 151 in 364,670 is how this was found.
- A new field carrying fvm::ddt is missing from discardStep(), so a retried step mixes two time levels. DETECTOR: one SIGFPE after exactly one discard; force it with maxCorrectors 3 (co1.5-forceretry) and confirm on an LMEA case, since all four original retryStep beds are LFA.
- Fields lead their own time label. DETECTOR: lead = sum(all reported 'current deltaT') - t_end, zero to the last digit when correct. Invalid when retryStep fired.
- A restart silently rewrites the snapshot it started from — including uniform/time's deltaT — while the FIELDS stay byte-identical. DETECTOR: compare the first step's dt across two restarts from 'the same' snapshot (measured 7.71e-12 vs 1.11e-11); cp -a + chmod -R a-w the restart point if it will be reused.
- A table lookup silently returns the table MAXIMUM because the axis is SI (V m^2) and the value was passed in Td. DETECTOR: identical output across two decades of field. Cross-check 1/nu_i = 14.19 ns at 431 Td and 0.731 ns at 2450 Td for argon ionisation.
- A guard compares an SI quantity against SMALL (1e-15) — reducedE sits at 1e-22..1e-19, so every cell is rejected. DETECTOR: print the active-cell count once and confirm it is non-zero.
- `+ SMALL` / `+ VSMALL` added to a denominator converts a divide-by-zero into an overflow. DETECTOR: grep the diff for '+ SMALL)' / '+ VSMALL)' inside a division, and compute the margin at the worst cell.
- A reported value equals a DEFAULT, a SEED or a CLAMP rather than a physical number (meanE max = 1 was the uniform seed; Te,max 1762.9 = (2/3)*2644.46 is the mean-energy clamp pinned, i.e. a reading from NON-CONVERGED steps). DETECTOR: compare every headline number against the case's own defaults and clamp values before interpreting it as physics.
- A per-gas quantity sums only the transported species and misses the 2.4e25 m^-3 untransported background. DETECTOR: estimate the answer by hand from the tables BEFORE looking (P*n_e*N*e/(rho*c_v)); a wrong gas density produces a perfectly plausible field. The identical code is CORRECT in the 0-D reactor.
- `[0-9]*` matches 0.orig, so cleaning time dirs deletes the initial-field templates and the error names the wrong cause ('cannot find file 0/ePotential'). DETECTOR: `ls $CASE/0.orig | wc -l` after any case copy, before launching.
- pgrep -f <pattern> matches the watcher running it; pkill -f <pattern> kills its own shell; pkill -f soPlasmaFoam matches NOTHING because the processes are `soPlasmaFoam -parallel`. DETECTOR: kill by name or PID; if -f is unavoidable, exclude self.
- `n=$(pgrep -c X || echo 0)` yields '0\n0' and breaks every numeric test, so an `until` loop never exits and the work never starts while being reported as running. DETECTOR: the log fills with 'integer expression expected'. Use `n=$(pgrep -c X 2>/dev/null || true); n=${n:-0}`.
- A liveness check inside a wait loop exits instantly because preprocessing (fields, seed, decomposePar, EEDF table rebuild) runs for minutes with NO solver process. DETECTOR: guard the break with `[ -s "$f" ]` and treat the case as alive if EITHER the solver ranks OR mpirun are up.
- A watcher started immediately after launch greps the PREVIOUS run's log and reports a failure that happened hours ago. DETECTOR: rm -f the log yourself, then `until [ -s "$d/log.soPlasmaFoam" ]; do sleep 5; done` before grepping.
- A hung parallel run busy-polls at 100% CPU on every rank (state Rl, inside PMPI_Waitall) and is indistinguishable from a slow one by step count. DETECTOR: log mtime staleness, not progress; then gdb -p <pid> -batch -ex "bt 8" BEFORE killing.
- An equivalence test passes because the shipped default makes the term negligible (gamma 0.001), or because the feature was never enabled (write() did not emit the key so the solver's rewrite erased it). DETECTOR: add a third NO-FEATURE column and raise the coefficient until the effect is visible; ask 'what would change if I deleted the feature?'.
- A comparison uses a solver-SERIALISED field as the baseline for GENERATOR output — the BC's write() adds refValue/refGradient/valueFraction/source — or the baseline has already been overwritten by the thing under test and the diff falsely PASSES. DETECTOR: PRINT the generated file and eyeball both sides; compare generator output to generator output with no solver in between.
- A default that depends on the model is an uncontrolled variable the moment the model differs (adaptiveRelaxation = hasLMEA; omega exists only for damping schemes). DETECTOR: diff the start-up BANNERS of the two arms, not the keys you edited.
- A capped distribution read for its tail looks bimodal. DETECTOR: count how many samples sit EXACTLY at the cap (38 solves at exactly 100); raise the cap and re-measure before drawing any shape conclusion.
- A too-clean null result — bit-identical arms across 48 steps, a signal that never prints, a step count an order of magnitude off — is evidence about the SETUP, not about physics. DETECTOR: stop and re-check the setup before interpreting.
- An analytic bed whose GEOMETRY does not match the formula it is compared against (plate2D bundles three walls into one patch, making it 2D Laplace with no analytic answer). DETECTOR: confirm the patch topology reduces to the formula's dimensionality before trusting the comparison.
